# Low-poly axe (Godot 4)

Open `res://scenes/tools/low_poly_axe.tscn`. Geometry and the `chop` AnimationPlayer clip are generated by `scripts/tools/low_poly_axe.gd` (also visible in the editor). The axe is 1.4 m long, with an eight-sided wood handle, wrapped grip and faceted metal blade. No external textures or plugins.

To use: instance the scene under the player's camera or XR hand. Call `$LowPolyAxe.swing()` on input; connect its `impact` signal to apply damage/harvest to the targeted tree exactly when the blade hits (0.31 s into the 0.56 s clip). `swing_finished` fires at the end. `swing_time` adjusts playback duration; `auto_swing_on_left_click` optionally handles mouse input. For first-person positioning, set local transform to roughly `(0.42, -0.40, -0.85)` and rotation to `(-18°, 0°, -22°)`.
